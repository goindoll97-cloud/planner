# 화학안전 계획서 작성 지원 시스템 (planner)

기업이 외부 컨설팅에 전적으로 의존하지 않고 **화학사고예방관리계획서(화사계)** 및 **공정안전보고서(PSM)**의 대상 여부를 사전진단하고, 필요한 자료만 단계적으로 입력하여 초안을 작성하도록 돕는 웹 기반 지원 시스템입니다.

## 설계 원칙

1. **회사 입력 최소화**: 사업장 기본정보 + 규격화된 화학물질 목록을 우선 입력합니다.
2. **법적 판정은 Rule Engine**: AI가 법적 대상 여부를 추측하지 않습니다.
3. **AI는 추출·정리·초안 작성**: 불명확한 사실이나 수치는 추정하지 않습니다.
4. **보류(hold) 우선**: 최신 법령 미반영, 필수값 누락, 물질 식별 불확실 시 확정판정을 하지 않습니다.
5. **법령·별표 PDF 버전 감시**: 법제처 현행본과 승인된 프로그램 반영본을 비교하고, 첨부 PDF는 SHA-256으로 내용 변경을 감지합니다.
6. **단계형 UI**: 대상 여부를 먼저 판단하고, 해당 사업장에 필요한 후속 정보만 질문합니다.

## 현재 구현 단계 (v0.2)

- Streamlit 단계형 웹 UI
- 회사용 최소 입력 Excel 템플릿 다운로드
- 사업장 기본정보 + 화학물질 Excel 업로드/검증
- 법제처 Open API 현행 법령·행정규칙 검색/본문 조회
- 감시대상 법령 registry (`data/law_registry.json`)
- 별표·서식 PDF 링크 자동탐색 및 다운로드
- 첨부 PDF SHA-256 기준선 비교
- 신규/변경 PDF를 `data/runtime/law_pending/`에 보관
- 법령 일련번호·시행일·공포/발령번호 변경 감지
- 변경/미검증 시 사전진단 강제 `판정보류`
- 관리자가 실제 규제DB/RAG/학습자료 반영을 완료한 뒤에만 기준선 승인

> **중요:** 기준선 승인 버튼은 경고 해제용 버튼이 아닙니다. 최신 공식 법령/PDF를 실제 프로그램 규제자료에 반영하고 검토한 뒤에만 승인해야 합니다.

## 법제처 API 설정

프로젝트 루트에 `.env` 파일을 만들고 신청·승인받은 국가법령정보 공동활용 인증값을 입력합니다.

```text
LAW_OC=발급받은_인증값
```

`.env.example`을 복사해서 사용할 수 있습니다. `.env`는 `.gitignore`에 포함되어 있으므로 GitHub에 올리지 않습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

실행 후 **관리자용: 법령·별표 PDF 변경 감시**에서 공식 최신본 조회 결과를 확인할 수 있습니다. 조회 결과는 1시간 캐시하며, `최신 법령·PDF 다시 확인` 버튼으로 즉시 재조회할 수 있습니다.

## PDF 변경 대응 흐름

```text
법제처 Open API 현행본 조회
        ↓
별표·서식 PDF 다운로드
        ↓
SHA-256 계산
        ↓
승인된 프로그램 반영본과 비교
        ↓
동일 → CURRENT → 판정 허용
변경 → UPDATE_PENDING → 판정보류
        ↓
새 PDF 재학습/RAG·규제DB 반영 및 검토
        ↓
관리자 기준선 승인
        ↓
다시 CURRENT
```
