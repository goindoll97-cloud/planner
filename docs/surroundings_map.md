# 주변 지도 조사와 시설 묶음

## 실행 준비

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

주소 조회에 필요한 `.env`는 [주소 API 시험 안내](address_api_smoke_test.md)를 따릅니다. 지도와 공간 계산에 Folium, streamlit-folium, Shapely, pyproj를 사용합니다.

## 실제 사업장으로 사용

1. 별지 제3호의 사업장 주소를 저장합니다.
2. 별지 제8호의 **1. 주소 조사·지도 정리**를 엽니다.
3. **주소로 주변자료 조사**를 누릅니다. 기본은 브이월드 건물 윤곽·환경 레이어 조회입니다. 카카오 장소명이나 국토정보플랫폼의 특정 시설명 조회를 추가로 선택할 수 있습니다.
4. 지도에서 부지 경계를 다각형 또는 사각형으로 그립니다. 기존 경계는 연필 도구로 수정하거나 쓰레기통 도구로 지운 뒤 새로 그릴 수 있습니다. 여러 면을 그린 경우 합친 영역을 사업장 경계로 사용합니다. EPSG:4326의 경도·위도 GeoJSON 경계를 가져올 수도 있습니다.
5. 경계를 대조한 도면·지도와 확인일을 적고 확인 항목을 선택한 뒤 **사업장 경계 저장·내외부 분석**을 누릅니다.
6. 조사 원이 경계 주변 범위를 덮지 못한다는 안내가 나오면 **경계 기준으로 다시 조사**를 실행합니다. 브이월드 조회 반경을 넓히되 API 조회 한도와 실패 안내를 계속 확인합니다. 카카오·국토정보플랫폼의 장소 검색은 기존 주소점 800m 조건을 유지합니다.
7. 시설 묶음 후보의 시설명과 구성 객체를 확인합니다. 필요한 경우 객체를 추가하거나 빼고 **시설 묶음 확인·저장**을 누릅니다.
8. 확인한 묶음을 **별지 제8호에 미검토 후보로 추가**합니다. 기존 보호대상 목록은 유지됩니다. 다음 목록 단계에서 법정 분류·최종 거리·현장 근거를 확인합니다.

## 지도와 거리의 의미

- 부지에 완전히 들어가는 도형은 기본 화면에서 숨기지만 원자료에는 남습니다. 내부 도형 표시를 켜면 다시 볼 수 있습니다.
- 경계에 걸치거나 접촉하는 도형은 별도로 표시하고 숨기지 않습니다.
- 장소 검색의 대표점이 부지 안에 있는 경우 시설 전체가 내부인 것으로 판단하지 않습니다.
- 거리 계산은 EPSG:4326 경도·위도를 EPSG:5179 미터 좌표로 변환해 수행합니다. 표시되는 값은 입력한 부지 영역과 도형의 최소거리입니다. 별지의 확정 거리 칸에는 자동 입력하지 않습니다.
- 이름 없는 도형도 원본 식별번호로 유지합니다. 건물 객체 수는 사업장 수나 보호대상 수가 아닙니다.
- 자동 묶음은 같은 이름, 같은 내외부 관계, 선택한 간격 안에서 연결되는 객체의 후보입니다. 다른 이름이나 이름 없는 객체를 자동으로 합치지 않습니다. 한 시설인지 여부는 담당자가 확인합니다.
- 조사자료나 경계가 바뀌면 관련 묶음을 다시 확인해야 합니다. 현재 주소가 조사 당시 주소와 다르면 다시 조사해야 합니다.

## 보존·내보내기

원래 객체 ID, 도형, 공급원 속성, 조회 시각과 안내를 프로젝트에 보존합니다. 묶음으로 정리해도 원본 건물은 삭제하지 않습니다. GeoJSON 다운로드에는 도형·출처·내외부 관계·담당자 확인 묶음이 들어갑니다. 이는 검토용 공간자료이며 제출용 지도 일련번호를 자동 작성하는 기능은 아닙니다.

기존 진단 JSON도 가져올 수 있습니다. 도형을 보존하기 전의 진단 파일은 위치 확인 필요로 표시될 수 있으므로 주소로 다시 조사하세요.

## 가상 예제로 시험

```powershell
python -m streamlit run examples/surroundings_demo.py
```

내부 건물, 외부 건물 두 개, 경계에 걸치는 건물, 이름 없는 건물, 부지 내부의 시설 대표점 등 여섯 개의 가상 객체가 표시됩니다. 부지 경계와 모든 객체는 가상이며 실제 주변 현황이나 사고 영향을 나타내지 않습니다. 실제 API 조회 버튼은 비활성화되며 수정은 예제 세션에서만 유지됩니다. 저장 버튼이 회사 프로젝트를 만들거나 변경하지 않습니다.

## 남은 범위

논·밭과 일반 산림의 면적자료 자동 조사는 아직 추가하지 않았습니다. `LT_C_WGISARECO`의 조회 미완료와 다른 레이어/API 한도·오류도 계속 표시합니다. 지도에 객체가 없거나 조회 원이 경계 주변 범위를 덮는 것만으로 조사 완료나 법정 보호대상 없음을 확정하지 않습니다.
