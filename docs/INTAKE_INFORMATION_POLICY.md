# 사전진단 입력정보 정책

## 목적

사전진단은 **신입사원이 회사에서 확인할 수 있는 사실만 입력**하고, 법령 적용·규정수량 계산·대상 여부 판단은 프로그램이 수행하는 것을 기본 원칙으로 한다.

입력 단계에서 전문적인 법률 용어나 모든 조건을 한꺼번에 요구하지 않는다. 사용자는 최대 두 개의 파일과 조건부 질문지만 사용한다.

## 입력 구조 — 최대 2개 파일 + 조건부 질문지

### 파일 1. 기본 물질목록 — 모든 사업장

한 행에 제품 하나만 적는다.

필수 또는 기본 입력:
- 제품명
- 단일물질 / 혼합물
- 단일물질인 경우 CAS No.
- 하루 최대 제조·사용량
- 최대 저장량
- 수량 단위(kg 또는 ton)

원칙:
- 단일물질은 CAS No.가 필수다. 물질명으로 CAS를 추정하지 않는다.
- 혼합제품은 제품 자체 CAS No.를 요구하지 않는다.
- 단일물질의 함량은 별도 정보가 없으면 100%로 처리한다.
- 혼합제품 구성성분을 기본 물질목록의 다음 행에 이어 적지 않는다.

### 파일 2. 혼합물 구성성분 — 혼합물이 있을 때만

기본 물질목록에 혼합제품이 있을 때만 프로그램이 해당 제품명이 미리 채워진 두 번째 양식을 제공한다.

사용자는 제품 SDS 제3항을 보고 다음만 작성한다.
- 혼합제품명
- 구성성분 CAS No.
- 함량(%)

원칙:
- 법적 물질 식별은 구성성분명이나 제품명을 추정하지 않고 CAS No.로 한다.
- 구성성분명은 필수 입력으로 요구하지 않는다.
- CAS 형식·검산번호와 함량 범위를 검사한다.
- 입력 성분 함량의 합이 100%를 넘으면 오류로 막고, 100%보다 부족하면 누락된 규제대상 성분이 없는지 확인하도록 안내한다.
- 입력값은 제품 SDS 제3항과 대조했다는 사용자 확인 후 저장한다.

혼합물이 없는 사업장은 파일 1만 사용한다.

## 조건부 질문지

법적 판정에 실제로 필요한 경우에만 화면에서 추가 질문한다. 회사가 이미 파일이나 이전 질문에서 준 값은 다시 묻지 않는다.

예:
- 상온·상압에서의 성상 또는 액체 여부
- 제품 SDS 제2항 유해성·위험성 분류
- 사업장 최대보유량 산정을 위한 시설 정보
- 화학사고예방관리계획서 작성 면제시설 여부
- 공정안전보고서 제외설비 여부
- 인화성 가스·인화성 액체 해당 여부
- 특수 성분조건
- 주요취급시설 여부

어려운 용어가 화면에 필요한 경우 질문은 짧게 쓰고 ? 도움말에 다음을 설명한다.
- 무슨 뜻인지
- 왜 묻는지
- 어디서 확인하는지
- 예시
- 모를 때 어떻게 해야 하는지

모름 또는 빈 값을 허용할 수 있는 항목은 추정하지 않고 판정을 보류한다.

## 사업장 업종 정보와 KSIC

사업장에는 사람이 읽기 쉬운 '업종 또는 주요 생산품'을 기본으로 받는다.

공정안전보고서의 업종 기준 확인에는 한국표준산업분류 코드가 필요할 수 있다. 화면에서는 '업종 분류 코드(KSIC, 알면 입력)'으로 표시하고 ? 도움말에서 다음을 설명한다.

- KSIC는 한국표준산업분류의 약자다.
- 사업장의 주된 일을 숫자로 구분한 코드다.
- 공정안전보고서는 일부 업종 자체가 대상 기준이 될 수 있어 사용한다.
- 회사에서 사용하는 5자리 코드를 알고 있으면 입력한다.
- 모르면 처음에는 비워 둘 수 있으며, 수량기준만으로 판정이 끝나지 않아 업종 확인이 필요한 경우 다시 안내한다.

잘못된 자리수의 코드를 유효한 업종 코드로 간주하지 않는다.

## UX 원칙

1. 회사가 이미 준 정보는 다시 질문하지 않는다.
2. 기본 물질목록에는 제품 단위 정보만 받는다.
3. 혼합물이 있을 때만 두 번째 구성성분 파일을 보여 준다.
4. 어려운 법률·기술정보는 처음부터 파일 열로 강제하지 않고 실제 판정에 필요할 때만 질문한다.
5. CAS가 필요한 법적 식별을 물질명으로 추정하지 않는다.
6. 자동 계산 또는 외부 참고자료(KOSHA 등)는 출처와 한계를 표시하고, 회사 SDS 확인이 필요한 내용은 사용자 확인 없이 확정하지 않는다.
7. 빈 칸, 0, 모름의 의미를 구분한다.
8. PFD, P&ID, 방류벽, 감지기, 비상조직 등 작성단계 자료는 대상 여부가 확정되기 전에 일괄 요구하지 않는다.
9. 판정 전 정보와 실제 보고서 작성정보를 분리한다.
10. 법적 판정에 결정적인 정보가 불확실하면 미해당으로 추정하지 않고 HOLD/확인 필요 상태로 둔다.

## 하위호환

기존 회사 파일에 함량, 성상, SDS 제2항 분류, 최대 동시보유량 등 추가 열이 이미 있으면 가능한 범위에서 읽어 보존한다.

과거의 한 시트 혼합물 양식도 읽을 수 있도록 유지할 수 있으나, 제품명이 빈 행을 임의로 앞 제품의 성분으로 추정하지 않는다. 바로 앞 제품이 명시적으로 혼합물인 경우에만 과거 성분 행으로 연결한다.
