# 사전진단 입력정보 정책

## 목적

사전진단 프로그램은 사용자가 업로드 후 화면을 계속 내려가면서 처음 듣는 필수정보를 뒤늦게 요구하는 방식이 아니라, **최종 판정에 필요할 수 있는 정보의 종류를 처음부터 안내하고, 회사가 이미 가진 정보는 최초 업로드에서 함께 받는 방식**을 기본으로 한다.

다만 모든 회사에 모든 정보를 요구하지 않는다. 정보는 다음처럼 구분한다.

- **기본 필수정보**: 대부분의 PSM·화학사고예방관리계획서 사전진단에 공통으로 필요한 정보
- **조건부 필수정보**: 특정 물질·농도·상태·시설·규정수량 구간에서만 필요한 정보
- **작성단계 정보**: 작성대상 확정 후에만 필요한 상세 공정·설비·도면·비상대응 정보

## 기본 필수정보

최초 회사 입력파일에는 적어도 다음 정보를 받는다.

- 사업장명, 주소, 업종 또는 주요 생산품, 가능하면 KSIC
- 제품명 또는 물질명, CAS No.
- 함량(%)
- 취급형태
- 하루 최대 제조·취급량 및 최대 저장량
- 수량 단위
- 알고 있는 경우 사업장 최대보유량

## 조건부 필수정보

아래 정보는 모든 회사에 요구하지 않지만, 해당 규칙이 발동되면 최종 판정을 위해 필요하다. 회사가 이미 알고 있다면 최초 파일에서 입력하도록 가이드한다.

### 공정안전보고서(PSM)

- 별표 13에서 별도 성분조건이 있는 물질의 성분함량(예: 발연황산의 SO3, 니트로셀룰로오스의 질소 함량)
- 규정량 산정에 영향을 주는 전문 가스 저장·판매시설 해당 여부
- 산업안전보건법 시행령 제43조제2항의 법정 제외설비 해당 여부

### 화학사고예방관리계획서

- 법정 방식으로 산정한 사업장 최대보유량인지 여부
- 별표 3에서 상태별 규정수량이 있는 물질의 상온·상압 액체 여부
- 별표 1 판정이 필요한 물질의 실제 회사/제품 SDS 제2항 유해성·위험성 분류, 특히 혼합물
- 규정수량 이상일 때 법정 작성 면제시설 해당 여부
- 상위 규정수량 이상일 때 주요취급시설 여부

## UX 원칙

1. 회사가 입력파일에 이미 준 정보는 다시 질문하지 않는다.
2. 조건부 필수정보가 비어 있을 때만 추가 질문한다.
3. 추가 질문을 띄우기 전, 최초 입력 가이드에서 그 정보가 어떤 경우 필요할 수 있는지 알려준다.
4. `모름`은 허용한다. 모르는 값을 추정하지 않고 해당 규칙만 `판정보류`한다.
5. PFD, P&ID, 방류벽, 감지기, 비상조직 등 작성단계 자료는 작성대상이 확정되기 전에는 일괄 요구하지 않는다.
6. 최종판정까지 필요한 정보와 보고서 작성에 필요한 정보를 구분한다.

## 현재 입력파일 확장 열

`02_화학물질목록`은 기존 열을 유지하면서 다음 선택 열을 추가할 수 있다.

- `상온·상압 액체 여부(해당 시)`
- `최대보유량 법정 산정 여부`
- `회사/제품 SDS 제2항 보유·확인 여부`
- `SDS 제2항 유해성·위험성 분류(선택 입력)`

기존 파일과의 하위호환은 유지한다. 선택 열이 없거나 값이 비어 있으면 필요한 경우에만 화면에서 확인한다.
