# 자료 중심 업무 공간

프로그램의 시작 화면은 ‘사업장 업무’입니다. 서식 칸을 채우는 대신 **회사 자료를 올리면 초안이 먼저 만들어지고,
사람은 규칙이 멈춘 예외만 처리**합니다. 기존 별지 작성·법적 대상 판정·계산 엔진은 유지합니다.

## 사용 순서

1. 사업장을 만들고 설비 자료와 물질 자료를 올립니다. CSV·XLSX·DOCX·HWPX·텍스트 PDF의 표를 읽고,
   PDF·DOCX·HWPX·TXT의 원문은 위치와 함께 보존합니다. 구형 HWP(바이너리)와 스캔 PDF(OCR)는 읽지 않습니다.
2. 읽는 즉시 규칙이 값을 걸러 **자동 기입**합니다. 사람 손이 필요한 값만 ‘확인할 일’에 남습니다.
3. ‘확인할 일’은 충돌 → 읽은 값 오류 → 자동 기입 보류 순서로, 결과를 바꿀 수 있는 값(★)을 먼저 보여 줍니다.
   - **충돌**: 같은 대상·항목에 서로 다른 값이 있으면 근거(파일·SHA256·시트/페이지·행·열·원문)를 보고 하나를 고릅니다.
   - **값 오류**: 범위(`10~20`)·단위 불명·수식 결과 없음·CAS 검산 실패·허용 범위 밖 값은 승인할 수 없고, 확인한 값을 직접 적습니다.
   - **보류**: 충돌은 없지만 신뢰도·단위·추출 경로가 불확실한 값. 표에서 읽은 값은 한 번에 일괄 확인할 수 있습니다.
4. ‘시나리오 후보’는 확인 전 값도 ‘잠정’으로 써서 **자료를 올린 직후부터** 물질×설비 순위를 보여 줍니다.
   순위를 바꾸는 빈 값만 골라 그 자리에서 물어봅니다.
5. ‘연결·내보내기’에서 확인된 사실만 기존 작성자료(`inventory.chemicals`, `inventory.facilities`)에 연결하고,
   별지 제1호에 이어진 결과와 아직 필요한 계산 입력을 확인합니다.

## 자동 기입 규칙

자동 기입은 다음을 **모두** 통과해야 합니다. 모델이 자신의 확신도를 말해도 승인 근거가 되지 않습니다.

| 검사 | 통과 조건 |
|---|---|
| 충돌 | 같은 대상·항목의 모든 출처 값이 같음 (같으면 오히려 교차 확인된 값) |
| 유효성 | 숫자 항목은 숫자, 허용 범위 안, CAS는 형식·검산, 선택형은 허용 값 |
| 단위 | 항목명에 단위가 있음 (`운전압력` ✗ / `운전압력(MPa)` ✓) |
| 추출 경로 | 표에서 읽음. 문장·로컬 AI·수동 후보는 자동 기입하지 않음 |
| 출처 신뢰도 | 아래 표 |

신뢰도는 *검토 우선순위*이며 실제 정확도나 법적 증명력이 아닙니다.

| 출처 | 신뢰도 |
|---|---|
| 설비번호·제품코드가 있는 표 | 0.98 |
| 수식 계산 결과 / 병합 셀에서 가져온 값 | 0.90 |
| 직접 표시된 `항목: 값` 문장 | 0.88 |
| 이름만으로 연결한 표 | 0.78 |
| 로컬 LLM 제안 | 0.55 |

**영향에 따라 문턱이 달라집니다.** 법적 판단에 쓰이는 항목(최대보유량·함량·CAS·용량·시설유형·성상·비중·공정유형)과
‘순위를 바꾸는 핵심값’은 0.98이 필요하고, 나머지는 0.90이면 됩니다. 즉 병합 셀의 운전압력은 자동으로 채우지만,
같은 병합 셀의 최대보유량은 사람에게 넘깁니다. 핵심값은 자동 기입했더라도 ‘먼저 볼 핵심값’ 목록에 올라
출처 확인 전까지 보고서에 ‘사람이 아직 보지 않은 값’으로 표시됩니다.

새로운 출처가 들어오면 해당 사실의 이전 결정(자동 포함)은 무효가 되고 규칙을 다시 적용하며, 연결된 작성자료는 HOLD로 돌아갑니다.

## 순위와 핵심값

예비 비교지표는 `최대보유량(kg) × (1 + 운전압력(MPa)) × 함량(%) / 100`입니다. 물질별 독성·인화성, 누출량, 성상,
차단설비, 날씨, 거리와 보호대상은 반영하지 않으므로 **검토 순서이지 위험도나 법적 판정이 아닙니다.**

값은 세 상태입니다.

- **확정**: 담당자가 확인했거나 규칙이 자동 기입한 값
- **잠정**: 아직 확인하지 않았지만 충돌·오류가 없는 후보값. 순위 계산에 사용합니다.
- **가정**: 값이 없거나 충돌·오류라서 임시값으로 대체한 값. 충돌이면 큰 값(보수적), 값이 없으면 같은 사업장 관측 최고값×1.5와
  보유량 10,000kg·압력 1MPa 중 큰 값, 함량 100%입니다. 안전한 상한이나 물성 추정이 아니며, 가정이 있는 후보는 ‘보류’로 표시하고
  작성자료나 계산에 자동 반영하지 않습니다.

두 가지 민감도를 봅니다.

- **가정 값**: 0 ~ 임시값의 2배로 움직여 순위가 달라지면 그 값을 먼저 물어봅니다.
- **실제 값**: 0.5배·2배로 움직여 순위가 달라지면 *핵심값*으로 표시하고, 자동 기입 문턱을 높입니다.

후보가 하나뿐이면 순위 민감도만으로 필요한 자료가 없다고 결론 내릴 수 없습니다. 취급 관계가 여러 물질로 모호하면 보류합니다.

## 읽기 지원 범위

- 제목·안내 줄이 위에 있어도 항목명이 가장 많이 모인 줄(앞 20줄 이내)을 머리글로 읽습니다.
- 엑셀 수식은 저장된 계산 결과를 쓰되 신뢰도를 낮추고, 계산 결과가 없으면 값 오류로 남깁니다.
- 병합 셀은 왼쪽 위 값을 펼쳐 읽되 표시합니다. 숨김 시트도 읽고 시트 이름에 표시합니다.
- 식별번호·명칭이 없어 건너뛴 행은 개수를 알려 줍니다. 연결하지 못한 열은 문서별로 표시합니다.
- 두 줄 이상으로 나뉜 머리글, 도면·P&ID, 혼합물 성분 관계의 완전한 모델링은 구현하지 않았습니다.

## 별지 제1호와의 관계

연결한 설비 행은 별지 제1호의 **직접 확인 최대보유량(kg)** 경로로 물질별 합산됩니다. 시설유형·물질성상·용량·비중·공정유형도
읽어 와서 별지 제1호 시설 입력 화면에 미리 채웁니다. 다만 별표 4에 따른 법정 산정(설계용량×비중 등)은 그 화면에서
저장할 때 일어나며, 회사가 적은 최대보유량과 산정값이 다를 수 있으므로 자동으로 이어 붙이지 않았습니다.
아직 필요한 입력은 ‘연결·내보내기’에 계산 엔진의 문장 그대로 표시합니다.

## 로컬 AI

선택 기능입니다. `LOCAL_LLM_PROVIDER`(ollama 또는 openai_compatible), `LOCAL_LLM_URL`, `LOCAL_LLM_MODEL`을 설정하고
대상 식별번호와 함께 PDF/DOCX/HWPX/TXT를 접수한 뒤 ‘로컬 AI 후보 제안’을 누릅니다. 원문에 연속된 인용구, 정확한 위치,
수치 및 같은 단위가 있는 제안만 후보로 접수하며, 접수한 후보도 자동 기입·일괄 확인에서 제외되어 한 건씩 사람이 확인해야 합니다.
문서 원문을 원격 모델로 보내지 않습니다.

## 시험 순서

‘가상 회사 시험자료 ZIP’을 내려받아 풀고, 01번은 제품·물질 자료로, 02~04번은 설비 자료로 올립니다.

- 02·03번: `TK-01` 용량 10m³/12m³ 충돌 → ‘확인할 일’에 1건
- 04번: 제목 줄·빈 줄 아래 머리글, 수식 셀(계산 결과 없음) → 값 오류 1건, 빈 보유량은 ‘가정’으로 순위 질문
- 나머지는 자동 기입

예제 조건은 실제 운전이나 위험평가에 사용할 수 없습니다. 새 화면은 원문 첨부와 구조화 후보를 기존 프로젝트 아래 저장하며
회사 자료·키를 GitHub에 올리지 않습니다. 일반적인 API 주소 조회 외에 업로드 문서 자체를 외부 AI로 보내지 않습니다.
