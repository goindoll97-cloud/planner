# 자료 중심 업무 공간

프로그램의 시작 화면은 ‘사업장 업무’입니다. 서식 칸을 채우는 대신 **회사 자료를 올리면 초안이 먼저 만들어지고,
사람은 규칙이 멈춘 예외만 처리**합니다. 기존 별지 작성·법적 대상 판정·계산 엔진은 유지합니다.

## 사용 순서

화면은 네 단계입니다. 신입사원이 화학사고예방관리계획서를 몰라도 따라올 수 있도록 사람 말로만 안내하고,
파일 지문(SHA256)·내부 식별자·JSON은 ④의 ‘검토·감사용 기록’에만 둡니다.

1. **① 자료 올리기**: 설비 자료와 물질 자료를 한 번에 올립니다. 머리글로 종류를 자동 분류하며 모호한 파일만 묻습니다.
   설비번호·제품코드 같은 식별자 열이 한쪽에만 있으면 그쪽으로 정하고(설비대장의 물질명·CAS 열은 보조 근거),
   식별자가 없으면 항목명이 한쪽으로 뚜렷할 때만 정합니다. 설비-제품 대응표처럼 두 식별자가 함께 있으면 묻습니다.
   CSV·XLSX·DOCX·HWPX·텍스트 PDF의 표를 읽고, 구형 HWP(바이너리)와 스캔 PDF(OCR)는 읽지 않습니다.
   읽는 즉시 규칙이 값을 걸러 **자동 기입**하고 ②로 넘어갑니다.
2. **② 질문에 답하기**: 사람이 답할 것만 질문 카드로 보여 줍니다. 같은 값을 두 번 묻지 않습니다.
   - **자료마다 값이 달라요**: 후보를 ‘10 m³ — 02_equipment.csv 2번째 줄 (자료에는 ‘10,000 L’로 적혀 있음)’처럼 단위 환산과 함께 보여 주고 하나를 고릅니다.
   - **읽을 수 없는 값**: 계산식만 있고 결과가 없는 엑셀 칸은 숫자와 사칙연산뿐이면 계산한 값을 제안합니다(셀 참조는 계산하지 않음).
     범위(`10~20`)·단위 없음·선택지에 없는 말·CAS 오류·허용 범위 밖 값은 이유를 말하고 맞는 값을 받습니다.
   - **순위를 정하려면 꼭 필요한 값**: 자료에 없는 값 중 시나리오 후보 순서를 바꾸는 것만 묻습니다.
   - **한 번 확인해 주세요**: 자동 기입을 보류한 값. ‘맞아요’ 한 번 또는 ‘다른 값이에요’로 처리합니다.
   - **자료에 없는 정보**: 설비마다 빠진 항목을 선택지와 한 줄 설명(시설유형·물질성상 등)과 함께 받습니다. 아는 것만 적습니다.
3. **③ 시나리오 후보**: 확인 전 값도 써서 **자료를 올린 직후부터** 물질×설비 검토 순서를 보여 줍니다.
   조합마다 어떤 값을 썼는지(채운 값 / 확인 전 / 임시값), 출처와 가정의 이유, 다음 할 일을 보여 줍니다.
   검토 초안(Markdown)을 내려받으면 모든 조합의 사용값·원문 위치·가정·남은 조사 항목을 한데 볼 수 있습니다.
   누출 위치·사고 유형·차단·주변 토지 이용 및 피해 계산은 아직 별도 검토가 필요합니다.
4. **④ 작성 화면으로 보내기**: 법적 계산에 쓰이거나 순서를 바꾸는 자동 기입값을 **한 번에 모아 한 번만** 확인한 뒤
   기존 작성자료(`inventory.chemicals`, `inventory.facilities`)로 보내고, 별지 제1호에 들어간 내용과 아직 필요한 계산 입력을 보여 줍니다.

## 자동 기입 규칙

자동 기입은 다음을 **모두** 통과해야 합니다. 모델이 자신의 확신도를 말해도 승인 근거가 되지 않습니다.

| 검사 | 통과 조건 |
|---|---|
| 충돌 | 같은 대상·항목의 모든 출처 값이 같음 (같으면 오히려 교차 확인된 값) |
| 유효성 | 숫자 항목은 숫자, 허용 범위 안, CAS는 형식·검산, 선택형은 허용 값 |
| 단위 | 항목명에 단위가 있음 (`운전압력` ✗ / `운전압력(MPa)` ✓) |
| 추출 경로 | 표에서 읽음. 문장·로컬 AI·수동 후보는 자동 기입하지 않음 |
| 출처 신뢰도 | 아래 표 |

신뢰도는 *검토 우선순위*이며 실제 정확도나 법적 증명력이 아닙니다.

| 출처 | 신뢰도 |
|---|---|
| 설비번호·제품코드가 있는 표 | 0.98 |
| 수식 계산 결과 / 병합 셀에서 가져온 값 | 0.90 |
| 직접 표시된 `항목: 값` 문장 | 0.88 |
| 이름만으로 연결한 표 | 0.78 |
| 로컬 LLM 제안 | 0.55 |

**영향에 따라 문턱이 달라집니다.** 법적 판단에 쓰이는 항목(최대보유량·함량·CAS·용량·시설유형·성상·비중·공정유형)과
‘순위를 바꾸는 핵심값’은 0.98이 필요하고, 나머지는 0.90이면 됩니다. 즉 병합 셀의 운전압력은 자동으로 채우지만,
같은 병합 셀의 최대보유량은 사람에게 넘깁니다. 핵심값은 자동 기입했더라도 ‘먼저 볼 핵심값’ 목록에 올라
출처 확인 전까지 보고서에 ‘사람이 아직 보지 않은 값’으로 표시됩니다. 법적 계산에 쓰이는 자동 기입값은 원자료·단위·현재 적용 여부를 사람이 확인하기 전까지 작성자료 연결을 차단합니다.

새로운 출처가 들어오면 해당 사실의 이전 결정(자동 포함)은 무효가 되고 규칙을 다시 적용하며, 연결된 작성자료는 HOLD로 돌아갑니다.

## 순위와 핵심값

예비 비교지표는 `최대보유량(kg) × (1 + 운전압력(MPa)) × 함량(%) / 100`입니다. 물질별 독성·인화성, 누출량, 성상,
차단설비, 날씨, 거리와 보호대상은 반영하지 않으므로 **검토 순서이지 위험도나 법적 판정이 아닙니다.**

값은 세 상태입니다.

- **확정**: 담당자가 확인했거나 규칙이 자동 기입한 값
- **잠정**: 아직 확인하지 않았지만 충돌·오류가 없는 후보값. 순위 계산에 사용합니다.
- **가정**: 값이 없거나 충돌·오류라서 임시값으로 대체한 값. 충돌이면 큰 값(보수적), 값이 없으면 같은 사업장 관측 최고값×1.5와
  보유량 10,000kg·압력 1MPa 중 큰 값, 함량 100%입니다. 안전한 상한이나 물성 추정이 아니며, 가정이 있는 후보는 ‘보류’로 표시하고
  작성자료나 계산에 자동 반영하지 않습니다.

두 가지 민감도를 봅니다.

- **가정 값**: 0 ~ 임시값의 2배로 움직여 순위가 달라지면 그 값을 먼저 물어봅니다.
- **실제 값**: 0.5배·2배로 움직여 순위가 달라지면 *핵심값*으로 표시하고, 자동 기입 문턱을 높입니다.

같은 설비 또는 같은 물질의 값이 여러 조합에 쓰이면 영향을 받는 조합의 점수를 **함께 다시 계산**합니다.
따라서 모든 설비가 한 물질만 다룰 때 그 물질의 함량을 일괄 바꿔도 상대 순위가 같다면 순위 핵심값으로 분류하지 않습니다.
이 비교는 한 값씩만 바꾸는 시험이며, 여러 값이 동시에 틀린 경우의 보증이 아닙니다.

후보가 하나뿐이면 순위 민감도만으로 필요한 자료가 없다고 결론 내릴 수 없습니다. 취급 관계가 여러 물질로 모호하면 보류합니다.

## 읽기 지원 범위

- 제목·안내 줄이 위에 있어도 항목명이 가장 많이 모인 줄(앞 20줄 이내)을 머리글로 읽습니다.
- 엑셀 수식은 저장된 계산 결과를 쓰되 신뢰도를 낮추고, 계산 결과가 없으면 값 오류로 남깁니다.
- 병합 셀은 왼쪽 위 값을 펼쳐 읽되 표시합니다. 숨김 시트도 읽고 시트 이름에 표시합니다.
- 식별번호·명칭이 없어 건너뛴 행은 개수를 알려 줍니다. 연결하지 못한 열은 문서별로 표시합니다.
- 두 줄 이상으로 나뉜 머리글, 도면·P&ID, 혼합물 성분 관계의 완전한 모델링은 구현하지 않았습니다.

## 별지 제1호와의 관계

연결한 설비 행은 별지 제1호의 **직접 확인 최대보유량(kg)** 경로로 물질별 합산됩니다. 시설유형·물질성상·용량·비중·공정유형도
읽어 와서 별지 제1호 시설 입력 화면에 미리 채웁니다. 다만 별표 4에 따른 법정 산정(설계용량×비중 등)은 그 화면에서
저장할 때 일어나며, 회사가 적은 최대보유량과 산정값이 다를 수 있으므로 자동으로 이어 붙이지 않았습니다.
아직 필요한 입력은 ④에 계산 엔진의 문장 그대로 표시합니다.

## 로컬 AI

선택 기능입니다. `LOCAL_LLM_PROVIDER`(ollama 또는 openai_compatible), `LOCAL_LLM_URL`, `LOCAL_LLM_MODEL`을 설정하고
대상 식별번호와 함께 PDF/DOCX/HWPX/TXT를 접수한 뒤 ‘로컬 AI 후보 제안’을 누릅니다. 원문에 연속된 인용구, 정확한 위치,
수치 및 같은 단위가 있는 제안만 후보로 접수하며, 접수한 후보도 자동 기입·일괄 확인에서 제외되어 한 건씩 사람이 확인해야 합니다.
문서 원문을 원격 모델로 보내지 않습니다.

## 시험 순서

①의 ‘연습용 가상 회사 자료 받기 (ZIP)’를 내려받아 풀고 네 파일을 한 번에 올립니다. 종류는 자동으로 분류됩니다.

- 02·03번: `TK-01` 용량 10m³/12m³ 충돌 → ②에 질문 1건
- 04번: 제목 줄·빈 줄 아래 머리글, 계산식 칸(=1500+500, 결과 없음) → ②에서 2,000 kg 제안, 빈 보유량(RX-02)은 순위 질문
- 나머지는 자동 기입

예제 조건은 실제 운전이나 위험평가에 사용할 수 없습니다. 새 화면은 원문 첨부와 구조화 후보를 기존 프로젝트 아래 저장하며
회사 자료·키를 GitHub에 올리지 않습니다. 일반적인 API 주소 조회 외에 업로드 문서 자체를 외부 AI로 보내지 않습니다.

## 큰 연습 자료와 정답표

①의 ‘실제와 비슷한 큰 자료 (파일 7개)’는 가상 회사 1곳(설비 40대, 제품 26개)의 자료입니다(`engine/stage2/demo_company.py`).
정답을 먼저 정하고 거기서 파일을 만들면서 현장에서 흔한 문제 30가지를 일부러 넣었고, ZIP 안의 `answer_key.json`에
정답과 문제 목록이 있습니다. 엑셀 여러 시트·숨김 시트·병합 칸·시트마다 다른 단위(L·ton·kPa)·결과 없는 계산식·합계 줄,
한글 윈도우 인코딩 CSV, 개정 MSDS(DOCX), 문장으로 적힌 설비 사양서(HWPX), 스캔 PDF가 들어 있습니다.
06 사양서는 표에 번호가 없으므로 올릴 때 그 파일의 번호 칸에 `RX-205`를 적습니다.

`tests/test_demo_company.py`가 정답표로 채점합니다. 현재 결과는 다음과 같습니다.

- 자동 기입 431개 중 정답과 다른 값은 일부러 넣은 띄어쓰기 오류(‘가상자일렌’) 1개이며, 물질 목록과 연결되지 않는다고 따로 알립니다.
- 일부러 넣은 문제는 모두 질문으로 남거나(충돌·범위·CAS 오타·계산식·단위 오타·선택지 밖 표기·빈칸·문장 값) 알아서 바로잡습니다(액상·가스·사용시설 같은 흔한 표기).
- 남는 질문은 약 50개이며, 정답표대로 답하면 폐기예정 탱크(운전압력 없음)를 뺀 모든 조합이 임시값 없이 계산됩니다.

이 채점은 우리가 만든 가상 자료에 대한 것이므로 실제 회사 자료의 정확도를 뜻하지 않습니다. 공개 MSDS 등 실제 문서로 같은 방식의 정답표를 만들어 재는 것이 다음 단계입니다.
