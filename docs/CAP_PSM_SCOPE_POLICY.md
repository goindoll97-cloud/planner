# CAP / PSM 물질범위 판정 원칙

이 프로젝트는 과거 `goindoll97` 프로젝트의 전체 규제 스크리닝 기능을 이식하지 않는다. 화학사고예방관리계획서(CAP)와 PSM 판정에 필요한 기능만 유지한다.

## 유지하는 기능

- 현행 공식 법령/PDF의 변경 감시와 해시 추적
- 승인된 규정표의 직접 CAS 대조
- 함량조건 및 규정수량 비교
- 법령에 CAS 하나로 특정되지 않은 염류, 화합물군, 혼합물, 반응생성물 등 포괄범위의 후보 탐색
- 법령 문장에 포함된 구성성분 CAS와 명시적 제외 CAS 보존
- 불확실한 물질범위는 `판정보류` 처리하여 false-safe 비대상 판정을 방지

## 현재 제외하는 기능

- 제한물질·금지물질 등 CAP/PSM 적용성 판정과 직접 관계없는 별도 규제제도
- PubChem 자동조회
- RDKit/SMARTS 구조판정
- LLM 기반 법적 물질 동일성 확정
- 연구용 validation/promotion/dashboard 모듈

구조판정이 현행 CAP 또는 PSM의 특정 포괄범위를 확정하는 데 실제로 필요하다는 것이 확인된 경우에만, 해당 규칙에 한하여 검증된 결정론적 구조규칙을 별도로 추가한다.

## 물질 판정 순서

1. 직접 CAS 규칙 대조
2. 법령의 CAS 없는/포괄 규제범위 후보 대조
3. 함량·성상 등 조건 확인
4. 최대보유량(CAP) 또는 제조·취급·저장량(PSM) 적용
5. 면제·제외조건 적용
6. 최종 적용성/군 분류

직접 CAS에 매칭되지 않았다는 이유만으로 비대상 판정을 하지 않는다. 별표 1·2의 포괄범위 DB가 미완성이거나 포괄범위 후보가 남아 있으면 최종 비대상 판정을 보류한다.
