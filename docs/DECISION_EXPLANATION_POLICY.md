# Stage 1 판정 근거 설명 원칙

공정안전보고서 또는 화학사고예방관리계획서의 작성·제출 대상 판정이 확인된 경우, 사용자 화면에는 법령명과 조문만 나열하지 않는다. 판정에 실제 사용된 회사 입력 사실을 해당 법적 요건과 연결하여 설명한다.

- 공정안전보고서: 「산업안전보건법」 제44조제1항, 「산업안전보건법 시행령」 제43조제1항·제2항, 별표 13을 기준으로 한국표준산업분류 사업 종류 해당 여부 또는 별표 13 비고 제7호 합산한 값(R)과 기여 물질을 설명한다.
- 화학사고예방관리계획서: 「화학물질관리법」 제23조제1항, 관련 시행규칙 및 행정규칙을 기준으로 실제 물질의 최대보유량과 하위·상위 규정수량의 관계, 주요취급시설 여부, 법정 예외 미해당 사실을 설명한다.
- 사용자가 입력하지 않았거나 승인 규정 DB로 확정되지 않은 사실은 설명문에 추정하여 넣지 않는다.
- 사용자에게 표시되는 제도명·파일명·시트명에는 `PSM`, `화사계`, `화관법` 등의 약칭을 사용하지 않고 법적 명칭을 사용한다.
